# ChatXD downloads

All your stream chats (Twitch, YouTube, Kick, TikTok) in one fast window, with
click-to-moderate user cards, per-platform commands, clips, ad-break alerts, an
OBS dock and a stream overlay.

## Download

Get the latest version from **[Releases](https://github.com/seanmarcano/chatxd-releases/releases)**:

- **`ChatXD_x.y.z_x64-setup.exe`**: Windows installer (recommended)
- **`ChatXD-x.y.z-portable.zip`**: no install, unzip and run `chatxd.exe`

Requires Windows 10 or 11. ChatXD tells you inside the app when a new version is out.

> Alpha builds aren't code-signed yet, so Windows may show an "unknown publisher"
> warning. Click **More info → Run anyway**.

## Getting started

1. Install and open ChatXD.
2. **⚙ Settings → Accounts → Connect Twitch**, then **Activate** and **Authorize** on twitch.tv.
3. Add it to OBS: **Settings → OBS setup** → copy the Dock link → in OBS,
   **Docks → Custom Browser Docks…** → paste → **Apply**.

Your login stays on your PC (Windows Credential Manager). ChatXD never sees your password.
